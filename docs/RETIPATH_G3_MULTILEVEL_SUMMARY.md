# RetiPath G2/G3 multi-level supervision 描述性汇总

2026-09-18。**Post-hoc descriptive analysis**。只读取既有报告、protocol 与 CSV/JSON，比较 A、C、E 的已保存评价结果。本文没有新增 primary claim、显著性检验、成功阈值或实验；G2 原 teacher 独立列示，未并入 G3 五个 teacher 的统计。

## 1. 事实摘要

- **Internal-state recovery：**G3 五个 teacher 中，每个 teacher 的三个配对 seeds 上，C 的 H1 h 和 BC s_B RMSE 均低于 A/E；BC pathway output o_B 的 RMSE 也均更低。G2 原 teacher 的三个 seeds 同向。这里的稳定性仅指这批固定运行。
- **Direct-BC intervention recovery：**G3 的 C−A 在 5/5 个 teacher 均值上为负，但 W01/W03 各有一个 seed 为正；C−E 在 4/5 个 teacher 上为负，W01 的三个 seeds 全为正。G2 的 C−A 三个 seeds 全为负，C−E 三个 seeds 全为正。局部 d_E 与端到端 logit 误差分别列示，不能用状态恢复代替干预恢复。
- **相对 extra-RGC 的 trade-off：**C 在所有 G3 teacher 的状态及 BC output 恢复上均优于 E；端到端干预误差的 G3 等权均值较 E 低 0.0069505089，但 W01 与独立列出的 G2 原 teacher 上更高。C 的 RGC excess CE 在 G3 4/5 个 teacher 和 G2 原 teacher 上高于 E。
- **RGC prediction：**G3 中 C−A 的 excess CE 在 4/5 个 teacher 均值上为负，跨 teacher 均值差为 −2.9499412e−5 nats/bin；W04 为正。C−E 的跨 teacher 均值差为 +2.5130873e−5 nats/bin，五个 teacher 的差值范围为 [−1.5898072e−5, +5.7777224e−5]。因此相对 A 未见一致的预测损失，相对 E 则存在多数 teacher 上的预测代价。原协议未定义“明显受损”的实用阈值，本文不追加二元判定，也不把这些数值概括为完全无损。

### 2.2 条件与可比性

A = RGC_ONLY；C = MULTILEVEL_MULTISCALE_JOINT；E = EXTRA_RGC_MULTISCALE。三者共用 frozen G1 architecture、同一 world 的 teacher/test 输入与三个配对初值，均为 180 steps、480 microbatches、1,920 次序列曝光。C 的 H/BC/R microbatches 为 150/150/180，A/E 为 0/0/480；A 补充槽重复 base R，E 使用 120 条独立 extra R 序列。

C 的训练监督是有限节点的 noisy h 和 o_B，以及 RGC events；s_B 没有直接 state target。C 的有效 scalar label 曝光为 2,332,800，A/E 为 460,800；C 的 H/BC/R 累计 loss 系数各为 60，A/E 的 R 总系数为 160。因此 C−A/C−E 是这些冻结条件的比较，同时包含观测层、RGC 曝光分配及目标组成的变化。E 是 exposure-matched、**非 information-matched control**；不能将差值解释为严格等信息条件下单独增加监督层的因果效应。

G3 每个 world 的 teacher 来自 G2 raw 坐标上独立 N(0,0.5²) 扰动并映射回原边界，同时使用独立 stimulus/noise/event draws。本文用 teacher instance 标识对应的 teacher/data world，不能将 world 差异归因于 teacher 参数一项。三个 student 初值也跨 world 复用；world/seed 不作为生物 population 样本。

### 2.3 归约、单位与配对

- 统一读取 `split=test, stratum=heldout_scales`：sigma_deg 为 0.225/0.45，每尺度 8 条序列，共 16 条；T=300，前 60 bins warmup，后 240 bins 计分。沿用已有逐序列指标、尺度内等权及两尺度等权归约，不重新汇总原始 trace。本文的状态、输出和 ambiguity 表均限于这一范围。
- RGC excess CE 单位 nats/bin，来自既有 evaluator-only teacher conditional probability 与 entropy。h、s_B、o_B 是全节点 clean teacher trace 的 RMSE，BC 两分支等权；这些 effective-unit 误差不是 mV 或生理单位。local d_E 是局部 direct-BC 传输贡献，其 normal 恢复误差也是该局部 block effect 误差。
- `BLOCK_DIRECT_BC_DRIVE` 沿用 d_E=uE=0、tonic gE=1、保留 BC/AC/history 的语义。logit intervention RMSE 对比 student/teacher 的 `delta_ell = ell_block−ell_normal`，使用共同 teacher 正常试次的过去 events；它是条件计算干预，不是 free-running spike 总效应或药理阻断。CSV 中该列仍名为 `primary_logit_intervention_rmse`，本文引用原指标，未把 C−A/C−E 升格为 G3 新 primary。
- 单 seed 差值为 `metric(C, seed) − metric(A/E, 同 seed)`；teacher 均值是三个 seed 的算术平均。G3 跨 teacher 均值是 W01–W05 五个 teacher 均值的等权平均。G2 不参与此均值、范围或方向计数。
- Cross-seed ambiguity 直接取既有 `rms_distance`：同条件在共同 held-out 输入上的三对 seed 距离。其 C−A/C−E 使用**对应 seed-pair**相减，不能称为三个单 seed 的真值恢复误差，也不能作为 posterior uncertainty 或参数可辨识性证明。只存在 p、h、s_B、o_B、logit_intervention 五项；现有文件没有 d_E ambiguity，本文记为未提供，不生成或填零。
- 配对 seeds 的固定顺序为 `2026091801 / 2026091802 / 2026091803`。Seed-pairs 顺序为 `(1801,1802) / (1801,1803) / (1802,1803)`，省略共同前缀 `202609`。负/正/零按未四舍五入差值计数，精确零才记 tie；无新增容差或成功门槛。误差的负差表示 C 更低；ambiguity 的负差只表示 C 的运行分散更小。
- 表中保留 8 位有效数字；所有均值和符号基于 CSV 原精度计算。G3 W03 的 excess CE 绝对水平高于其余四个 world，等权均值保留该值，不删去或重新加权。
