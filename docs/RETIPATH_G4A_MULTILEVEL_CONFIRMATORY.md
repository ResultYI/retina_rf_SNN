### 1.3 公平性与训练账本

A = RGC_ONLY_BASE；C = MULTILEVEL_JOINT；E = EXTRA_RGC。三个条件均为 **180 optimizer steps**，batch=4，所有 12 个 raw 参数从第一步起可训练。Adam lr=0.01、betas=(0.9,0.999)、eps=1e−8、weight_decay=0，clip_grad_norm=1.0。CPU float32，评价归约 float64，每进程一个计算线程，最多三个训练进程并行。

| 条件 | base R batches | 额外 H / BC / R batches | 总 batches | 序列曝光 | 有效 scalar targets |
| --- | ---: | ---: | ---: | ---: | ---: |
| A | 180 | 0 / 0 / 0 | 180 | 720 | 172800 |
| C | 180 | 150 / 150 / 0 | 480 | 1920 | 2332800 |
| E | 180 | 0 / 0 / 300 | 480 | 1920 | 460800 |

每一步 A/C/E 的 base RGC 文件、events、batch 索引、mask、loss 归约和系数都相同；每 fit 为 180 base R batches、720 次 base 序列曝光。C 在每个六步周期的位置 1–5 加 H、位置 2–6 加 BC；E 在这些共 300 个额外槽使用 independent extra R。A 不补重复 R 槽，因此其总曝光较少。这是本轮针对旧 A 的公平性修正，不能与 G2/G3 旧 A 当作同一个训练条件。

Loss 沿用 G1 observation_loss：H/BC Gaussian NLL（略去固定常数），R Bernoulli NLL；先序列内有效 scalar 平均、再 batch 平均。H/BC/R 系数为 0.4/0.4/1⁄3；同一步各项累加，不再除以 batch 数。各条件 **base R 累计系数均为 60**；C 额外 H/BC 各 60，E 额外 R 为 100。C/E 的额外 batch 数相同，但 scalar targets、信息量和 loss 贡献不同；E 仍**不是 information-matched control**。梯度裁剪作用于总梯度，所以同 base R 数据/权重也不等于整个优化过程中相同的 base-gradient 更新效果。

### 1.4 评价与报告规则

全部 45 份最终 checkpoint 锁定后，才为每个 world 写入 TEST_CONSUMED.json 并读取测试目标。teacher/student、normal/block 使用同一条 teacher 正常试次的过去 events；无自由运行事件重采样。

- h/s_B/o_B RMSE 使用 clean teacher 的全节点读数，BC 两分支等权。它们分别代表 H1 state、BC state、BC pathway output；h 恢复不自动等于独立 feedback coupling 恢复。
- BLOCK_DIRECT_BC_DRIVE 保留 d_E=uE=0、tonic gE=1、BC→AC 支路与共同 history；从原始初态重算下游。指标是 student 与 teacher 的 `delta_ell = ell_block−ell_normal` 之差 RMSE，不等同 BC-cell silencing、药理阻断或 free-running spike 总效应。原 CSV 列名 `primary_logit_intervention_rmse` 保留。
- 四项 primary 与 excess CE 均先沿用已有逐序列计算，再尺度内等权、对 held-out 0.225/0.45 两尺度等权。每 fit 对应 16 条序列、最后 240 bins；excess CE 单位 nats/bin，其余沿用模型 effective/logit units。
- 每个 teacher 报告三个配对 seeds 的 C−A、C−E，teacher 均值是三者等权平均；跨 teacher 均值及范围只含五个新实例。负值表示 C 的误差更低，精确零记 tie。无结果后容差、排名筛选或成功门槛。
- Ambiguity 使用三对 seeds 的 p、h、s_B、o_B 和 logit intervention effect 在共同 held-out 输入上的 RMS 距离。C−A/C−E 对应相同 seed-pair 相减；较低距离描述运行分散较小，不能替代真值恢复或视为 posterior uncertainty。seed-pairs 有共享模型，不作为独立样本。
- 既有 evaluator 附带保存 all/seen/各 scale、节点子集、NLL、local d_E、teacher RMS 和相对 intervention error，均为辅助明细，不增加 primary。不将四个主要误差平均成机制总分。
